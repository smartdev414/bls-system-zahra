# This repo is DeafSign, not Teach Me Sign

This is the **DeafSign** platform (https://bsl.deafsigns.co.uk, repo `smartdev414/bls-system-zahra`), a separate
client's copy of the Teach Me Sign platform (`/opt/tae/bls/bls-system`, https://classroom.tms.webcam). The two
evolve independently: make changes for DeafSign here only, and never port them to the original (or back) unless
the user asks for that specific change on both.

Deploys, server layout and the one shared piece (the original's Caddy) are in [docs/DEPLOY-OVH.md](docs/DEPLOY-OVH.md).
